# Crystal Ball Themes

A small Mac app for swapping themed video sets on a USB "electronic crystal ball": the 70 mm
glass-dome toy with a round 480 × 480 screen. Built so the kids can switch the ball on the
front door from Halloween to whatever comes next without anyone fiddling with video converters.

![Crystal Ball Themes](docs/screenshot.png)

It works with the ball's stock firmware. The ball plays every MP4 in its `video` folder; this app
puts the right files there, in the exact format the ball expects, and never loses what was there before.

## Using it

1. Turn the ball **off** (hold the middle button for 3 seconds).
2. Plug it into the Mac with a **data** USB-C cable.
3. Hold the middle button until a USB picture appears on the ball. The app shows **Ball connected**.
4. Press **Show on the ball** on a theme.
5. Press **Eject the ball**, unplug it, and hold the middle button to turn it on.

On the ball, left/right on the dial skip between clips, and holding them changes the volume.

### Themes

- **🎃 Halloween** comes with the app: six original animations (jack-o'-lantern, friendly ghost,
  bats and moon, eyes in the dark, bubbling cauldron, and a "Happy Halloween!" title), each with its own sound.
- **📼 Original videos** is what was on the ball when it arrived, so you can always switch back.
- **🦇 Nightmare Before Christmas** starts empty. Open it and drag in clips or pictures you have.
- **+ New theme** makes your own: Christmas, birthdays, anything.

Dropped files are converted for you: MP4, MOV, GIF, JPG, PNG and iPhone HEIC photos all work.
**Fill the circle** crops to cover the round screen; **Show the whole picture** shrinks it to fit
inside the circle. Pictures become a 10-second slow zoom.

### Nothing is lost

Before a theme replaces the ball's videos, the app checks each file on the ball against every
theme it knows. Anything new is copied into a **💾 Saved from ball** theme first. Deleting a theme
or clip moves it to the Bin.

## Installing

The app lives at `~/Applications/Crystal Ball Themes.app`. To rebuild and reinstall it:

```bash
npm run package
```

```bash
ditto "dist/Crystal Ball Themes-darwin-arm64/Crystal Ball Themes.app" ~/Applications/"Crystal Ball Themes.app"
```

Converting your own clips needs ffmpeg (`brew install ffmpeg`). Built-in themes and switching don't.

## Developing

Requirements: Node 22.19+ (`nvm use`), ffmpeg/ffprobe, and `uv` for the Python tools.

```bash
npm install
```

| Command | What it does |
| --- | --- |
| `npm start` | Run the app from source |
| `npm test` | Unit tests (`node:test`), including a real ffmpeg conversion |
| `npm run ball -- status` | What's connected and which theme it's showing |
| `npm run ball -- apply builtin/halloween` | Put a theme on the ball from the terminal |
| `npm run ball -- add user/<slug> clip.mp4 [--fit]` | Convert files into a theme |
| `npm run ball -- eject` | Unmount the ball |
| `npm run themes` | Re-render the Halloween clips (`tools/make_halloween.py`) |
| `npm run icon` | Re-render the app icon |
| `npm run screenshot` | Launch, screenshot the window to `dist/screenshot.png`, quit |
| `npm run package` | Build `dist/Crystal Ball Themes-darwin-arm64/` |

The rendered Halloween MP4s are not committed. Run `npm run themes` after cloning.

### Layout

```
src/lib/       plain Node modules shared by the app and the CLI
  ball.js      find the ball (ioreg + mount), write clips safely, eject
  convert.js   ffmpeg arguments for the ball's format
  themes.js    theme folders, theme.json, save-from-ball, hash index
  apply.js     put a theme on the ball; work out what's on it now
src/main/      Electron main process + preload (the only code with file access)
src/renderer/  the UI (sandboxed, talks through window.ballApi)
src/cli.js     the same operations from the terminal
tools/         Python generators for the Halloween clips and the icon
test/          node:test suites
docs/          hardware notes and the screenshot
```

Your themes live in `~/Library/Application Support/Crystal Ball Themes/themes/`. Set
`CRYSTAL_BALL_DATA_DIR` to use somewhere else, for example while testing.
